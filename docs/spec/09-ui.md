# 09 — UI

One React app (`apps/web`) for the desktop window and the phone PWA. Components and exercise renderers
in `packages/ui-kit`.

## Layouts

- **Desktop (≥ 1024 px)**: left sidebar (navigation), main area, right context panel (lesson vocabulary,
  rule notes, "ask about this exercise" mini-chat). Keyboard shortcuts for answers (1–4, Enter, Space to
  play audio, hold N / T for push-to-talk in native / target language).
- **Phone**: bottom tab bar (Today · Course · Review · Chat · More), lesson in full screen, primary actions
  in the thumb zone, two large push-to-talk buttons (native / target language), safe-area aware.
- Same routes and state on both; the layout adapts, features do not differ. Owner-only screens (Models,
  Server) are shown on the owner device (desktop app) or after entering the owner PIN (06).

## Word sheet

Tap a word anywhere: target form with article colour, plural/forms, translation, audio, image (pick),
examples from met lessons, "add to cards", rule notes.

## Onboarding wizard (first run, owner)

MVP: a minimal first-run in the web app (owner profile, languages, course install, LLM URL test,
microphone test). The full wizard below comes with the desktop app (stage 12).

Each step has a "Test" button and can be skipped where marked.

1. **Language**: UI language (en/ru/de), native language, target language.
2. **Profile**: name, optional PIN.
3. **Courses**: catalog filtered by languages; pick course(s) and editions → install job with progress.
4. **LLM** (skippable — app works without it, minus scenes and free checking): choose and follow short
   steps with links: LM Studio (lmstudio.ai — install, download recommended model, start server), Ollama
   (ollama.com), built-in runtime (after MVP), OpenRouter (openrouter.ai — key),
   OpenAI / Anthropic (key), remote URL. Recommendation based on this machine's memory.
5. **Speech**: download whisper model; microphone test ("say: Guten Morgen") with result; pick voices,
   listen.
6. **Phone** (skippable): explain options (06): Tailscale (tailscale.com/download, `tailscale serve`),
   own domain / VPN with a valid certificate, plain HTTP (works, but no microphone).
   Then QR → open on phone → "Add to Home Screen".

New profiles created from a phone get a short wizard: name/PIN, languages, courses already installed.

## Design system

**Character**: calm study tool; content first; large readable target-language text; no noise.

**Colour**
- Grammatical gender is the main visual language and **reserved**: der = blue, die = red, das = green
  (plural = neutral). These hues are not used for anything else.
- Accent: Berlin U-Bahn yellow for primary actions, progress, highlights of lesson phrases.
- Neutrals: "ink" and "paper"; correct/incorrect use distinct hues **plus icons** (colour-blind safe),
  never the gender hues.
- Tokens as CSS variables; light and dark themes; follows system by default.

**Type**: Barlow (UI, body) and Barlow Semi Condensed (headings); generous size for target-language text.

**Components**: shadcn/ui on Radix (accessible primitives) + Tailwind; icons Lucide; pictograms from
ARASAAC/OpenMoji for words (04) — the app's "illustration" layer.

**Motion**: Motion (framer-motion) only where it informs: answer feedback, card flip, page transitions,
progress fill. Respect `prefers-reduced-motion`.

**Accessibility**: WCAG AA contrast, full keyboard use on desktop, screen-reader labels, focus states,
touch targets ≥ 44 px.

## Progress and motivation

- Course map with statuses; **can-do list** per level ("I can introduce myself", …) ticked from evidence.
- Words in long-term memory (FSRS stability ≥ 21 days) and rule mastery charts.
- Study-days calendar without streak loss or penalties.
- Badges and a switch to hide motivation features are "later".

## Internationalisation

- UI languages: **English (default), Russian, German** from the first release. All strings in message
  catalogs (ICU MessageFormat, plurals); no hard-coded text; CI fails on missing keys.
- Content languages are independent of UI language (02): a Russian UI can study German or English.
- Dates, numbers, plurals via `Intl`.
