# 09 — UI

One React app (`apps/web`) for the desktop window and the phone PWA, including components and exercise
renderers.

## Layouts

- **Desktop (≥ 1024 px)**: sidebar navigation, main area; in the lesson a sidebar with the lesson plan,
  the tutor and reference tabs open in sheets. Keyboard shortcuts for answers and audio.
- **Phone**: bottom tab bar, lesson full screen, primary actions (and later push-to-talk) in the thumb
  zone, safe-area aware.
- Same routes and features on both; the layout adapts. Owner-only screens need owner access (06).
- Navigation today: Courses · Settings. Planned: Today · Course · Review · More.

## Screens

Built (routes in `apps/web/src/routes/router.tsx`):

| Screen | Route | Content |
|---|---|---|
| **My courses** | `/` | the started courses: progress and the lesson to continue |
| **All courses** | `/catalog` | every installed course, a card per course and language pair ("русский → немецкий") with its source and licence; two lists narrow it: course and language pair (kept in the profile) |
| **Course map** | `/course/$series/$course` | description; "About the course": source and licence, counts (units, lessons, exercises, items, words, media by kind, size), integrity check, sync with the source (progress log); units and lessons with status |
| **Lesson player** | `/lesson/$series/$course/$lesson` | overview · video / exercise pages · reference tabs (vocabulary, grammar, culture, script, PDFs) · "Why is this wrong?" · lesson tutor · summary with AI practice (session review, writing, scene) |
| **Settings** | `/settings` | UI language, theme, LLM provider and model (with "test", LM Studio, "What the model gets", prompt button) |

The tutor and scenes live in the lesson; there is no separate chat screen.

Planned:

| Screen | Content |

Also planned: the course map's exams and can-do list; settings for speech (mic test, voices), SRS
limits, federal state, export profile; the **word sheet** (tap a word anywhere: target form with
article colour, plural/forms, translation, audio, examples from met lessons, history of answers, "add
to cards", rule notes).

**Target language**: the open course's edition gives the language it teaches (`ru-en` → English); target-
language text carries that `lang`, answers are checked with its rules, and UI strings never name a language
(the writing task takes the language's name from `Intl.DisplayNames`).

**App icon**: a dark speech bubble with a yellow anchor on the yellow tile (`apps/web/public/favicon.svg`,
the master); home-screen and install icons (iOS, PWA, maskable) are rendered from it, and the desktop app
takes its icons from it (stage 12).

**Audio player**: play/pause, a timeline to drag or click (arrow keys jump 5 s), elapsed and remaining
time, speed 1× / 0.75× / 0.5× (a profile setting, shared by all audio); the full size (lesson audio,
exercise audio) adds a caption and "back 5 s", the compact one sits in an item. Single words keep a
one-tap button. One medium plays at a time; a file that cannot load says so.

A lesson without exercises (a vocabulary section) goes from the overview straight to the summary with its
words and the AI practice; the lesson tabs list only what the lesson has.

Every screen has explicit empty and error states (no course installed, no LLM configured, microphone
unavailable or on plain HTTP, server unreachable), each with the action that fixes it.

## First run (planned)

- **Owner (MVP)**: the owner setup link (06) opens a minimal first run: profile, languages, course
  install with progress, LLM test, microphone test. The full wizard comes with the desktop app (stage 12).
- **New profile from a phone**: name/PIN, languages, courses already installed, own LLM settings
  (skippable).

## Design system

- **Character**: calm study tool; content first; large readable target-language text.
- **Colour**: grammatical gender is **reserved**: der = blue, die = red, das = green (plural neutral);
  these hues are used for nothing else. Accent: U-Bahn yellow. Correct/incorrect use other hues plus
  icons. Tokens as CSS variables; light and dark themes, following the system.
- **Type**: Barlow (UI, body), Barlow Semi Condensed (headings).
- **Components**: shadcn/ui on Radix + Tailwind; Lucide icons; Motion only where it informs; respects
  `prefers-reduced-motion`.
- **Accessibility**: WCAG AA contrast, keyboard use on desktop, screen-reader labels, touch targets ≥ 44 px.

## Internationalisation

- UI languages: English (default), Russian, German from the first release. All strings in ICU message
  catalogs; no hard-coded text; CI fails on missing keys. Dates, numbers, plurals via `Intl`.
- Content languages are independent of the UI language.
