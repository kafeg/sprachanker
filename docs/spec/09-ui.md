# 09 — UI

One React app (`apps/web`), components and exercise renderers included, for desktop and phone screens
(served by `sprachanker serve`; the desktop window: plan, "Desktop app"; phones: plan, "Phones").

## Layouts

- **Desktop (≥ 1024 px)**: sidebar navigation, main area; in the lesson a sidebar with the lesson plan,
  the tutor and reference tabs open in sheets. Keyboard shortcuts for answers and audio. The
  sidebar's foot: the profile, "On a phone" under it (Settings → General → Other devices, opened
  beside; owner's choice C, 2026-10-11 — a phone has them in Settings only), the version.
- **Phone**: bottom tab bar, lesson full screen, primary actions in the thumb zone, safe-area aware;
  a bar of actions keeps to one row (the lesson's and an exam run's Back an arrow, the onboarding's Back and Next fixed
  at the bottom), the lesson's reference tabs that do not fit wrap rather than scroll out of sight, a
  section's tabs (and Settings') keep to one row — the three of a section put their counts under the
  labels, Settings' fit a phone in every language with the AI tab named short there ("AI") —, a choice's options share the row they wrap into (an exam's module switch: the whole exam a row of its own, the modules two to a row), and a list of decks shows a pair by its flags.
- Moving between pages: a new page opens at its top; Back returns to where a page was left.
- Same routes and features on both; the layout adapts. Every profile is equal: no owner screens (06).
- Navigation: Courses · Review (with the number of cards due) · Exams · Tutor · Notebook · Settings.
  Tutor is there while the assistant works there (a model set up, the tutor's place on), else absent,
  as every AI place; on a phone the tab bar has six entries then. Every label fits its sixth of a 375 px
  screen whole in the bundled fonts, semibold as when it is open (measured, 2026-10-11): where a
  language's own word does not, the tab bar names the entry short below 640 px (`nav.short.*` —
  Review and Settings, e.g. "Karten", "Optionen", "Повтор", "Ajustes"; the full name stays its
  accessible name), as Settings' AI tab; on a narrower screen a label wraps, hyphenated by the
  language (`lang` of the page), never spilling into the next.
- Window title: "SprachAnker · <where you are>" in about ten characters (My courses, Course, Tutor, Lesson 1.1,
  Ex 4/12, Summary, Settings); a running course download shows "↓ 45 %" there instead.

**Word bank**: one gap is active (the first empty one, or the one tapped) and a tapped word goes there;

**Order of options**: options, parts, word banks and drop-down lists are shown in an order of their own

**Gaps**: a drop-down gap is the app's list with a mouse and the system's own picker on a touch screen

text touching it before (a stem with its ending as the gap — "mein[em]", no space added —, an opening

"[gap] ." reads "[gap]."), letters or a hyphen touching it ("[gap]'s", "[gap]-Kurs"); an ellipsis or an opening quote after a
space stays apart; the space after the unit is its margin, so a line broken there starts with the word. An answer ending with the mark the text puts after the gap shows it once ("da." +
"." reads "da."; the answer itself unchanged). An option of only a dash (no word there) reads
"— (nothing)". A word bank's slots have one width at least — its longest word and the mark —; a

## First run

The first profile, and every new one, goes through the onboarding (Screens): its AI step sets up the
assistant (LM Studio included), its speaking step tests the microphone, downloads a recogniser
model and sets up reading aloud; both optional.

## Design system

- **Character**: calm study tool; content first; large readable target-language text.
- **Colour**: grammatical gender is **reserved**: der = blue, die = red, das = green (plural neutral);
  these hues are used for nothing else. Accent: U-Bahn yellow. Correct/incorrect use other hues plus
  icons. Anki's colours take ours: Again and learning cards as wrong, Good and cards to review as
  correct, Easy and new cards a violet of their own (`srs-new`), Hard grey; only the seven flag icons
  keep Anki's colour names. Tokens as CSS variables; light and dark themes, following the system.
- **Type**: Fira Sans (UI, body), Fira Sans Condensed (headings) — one face for Latin, Cyrillic and
  Greek, so a Russian or Greek sentence with a German word in it is set in one font (Barlow, before,
  has no Cyrillic); other scripts by faces after it (Vazirmatn for Arabic and Persian, Noto Sans
  Devanagari; Chinese in the system's CJK font — PingFang, Microsoft YaHei, Noto CJK; 10).
- **Components**: shadcn/ui on Radix + Tailwind; Lucide icons; Motion only where it informs; respects
  `prefers-reduced-motion`.
- **Accessibility**: WCAG AA contrast, keyboard use on desktop (Space and Enter on a focused button or
  link are that control's, never a screen's shortcut), screen-reader labels (no link inside a
  button), touch targets ≥ 44 px on touch screens (`pointer-coarse:`, buttons by default).

## Internationalisation

- UI languages: English (default, the fallback) and every language there is a catalog for — one ICU
  message file per language (`apps/web/src/i18n/<code>.json`), offered once its file is there (no list
  to keep); the aim is every language a course explains in (plan). English is in the main bundle;
  every other catalog is a chunk of its own, loaded when first chosen (the start language's before
  the first screen). A catalog that does not load changes nothing — the language, its direction and
  what the device and profile keep stay — and the page reloads once (the app was most likely
  upgraded under it; not again until a catalog loads); at start, English stands in. All strings in
  the catalogs; no hard-coded text; CI fails on missing keys and checks every catalog (10). Dates,
  numbers, plurals via `Intl`.
- The start language: the one chosen on this device, else the browser's first one there is a catalog
  for, matched on its primary subtag (`zh-TW` takes the Simplified Chinese catalog, `pt-PT` the
  Brazilian Portuguese one), else English.
- The language list (who is studying, Settings → General): a drop-down list, each language named in its
  own (`Intl.DisplayNames`), in the order of those names (as Wikipedia lists its languages: Latin
  script first, then Greek, Cyrillic, Arabic, Devanagari, Chinese) — no language favoured; the one in
  use shows in the closed list.
- Right-to-left interface languages (Arabic, Persian — the direction from `Intl.Locale`'s text info,
  else a list): the page is `dir="rtl"`, the layout mirrored (Writing direction).
- Content languages are independent of the UI language.
