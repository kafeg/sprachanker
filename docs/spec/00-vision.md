# 00 — Vision

## Problem

Good free language courses exist (Deutsche Welle "Nicos Weg", open textbooks), but they are weak exactly
where a self-learner struggles most: speaking and writing practice with feedback, long-term vocabulary
retention, and explanations in the learner's own language. Commercial apps lock data and content behind
subscriptions. LLMs give feedback but, used alone, invent curricula and hallucinate rules.

## Product

SprachAnker is a self-hosted learning app that:

1. **Installs real courses** into a local library through importers (downloaded by the user, for the user).
2. **Presents them in one consistent UI** in the browser — on the desktop now; on phones, as a
   PWA, later (plan, "Phones").
3. **Adds what courses lack**: speaking checked by recognition and the AI, spaced-repetition cards for
   every word met, LLM scenes and free-text checking scoped to what the learner already knows. Planned:
   mistakes by grammar rule and contrastive notes in the learner's language (plan, "Enrichment and
   rules").
4. **Records everything** the learner did, so progress and mistakes can be seen and gone over later.
5. **Uses any model the user chooses**: local via LM Studio, or OpenRouter / any OpenAI-compatible server.

## Users and setting

- Primary: a Russian-speaking adult in Germany learning German from A1. A second user in the same
  household with her own profile. Both use iPhones; the server runs on a MacBook Pro (M2 Pro, 32 GB).
  Another machine (RTX 3080 Ti) may serve as a remote LLM box.
- Secondary (once public): anyone who can run a desktop app and wants a private tutor with real courses.

## Core scenarios

1. **Learn a lesson**: episode, exercises, checked speaking, new cards, summary. Resume where left off
   on any device.
2. **Daily review**: due cards, 10–15 minutes.
3. **Speak**: short LLM scenes restricted to known material; corrections recorded.
4. **Look back**: the Notebook shows every attempt, recordings and mistakes.
5. **Free chat**: ask about grammar in the native language, chat in the target language, discuss recent
   mistakes.
6. **Prepare for tests**: the Nicos Weg final tests (lessons); exams such as Leben in Deutschland:
   plan, "Exams".
7. **Set up**: run the server, pick languages, install a course, connect a model.

## Principles

- **Local-first, private.** All data stays on the user's machine. No telemetry.
- **Real courses first, LLM second.** The curriculum comes from courses; the LLM checks, explains and
  converses inside it. Course content is never generated or enriched by an LLM: importers and
  normalisers are deterministic code over the source — import, normalise, and the course is ready.
- **Deterministic where possible.** Closed exercises are checked by code; LLM only for open answers.
- **Everything is replayable.** Append-only event log; statistics are derived and rebuildable.
- **Language-pair agnostic.** German/Russian is the first pair, not an assumption.
- **Simple over clever, coherent over quick** (engineering principles in the root CLAUDE.md).

What is built, and the decisions that are expensive to change, are in this spec; what is left, in
order, is in `docs/plan.md`.

## Non-goals

- A cloud service or accounts; app-store distribution.
- Courses fully generated by an LLM.
- Strong multi-user security. Profiles separate data; they do not defend against people on the same LAN.
- Gamification that punishes (streak loss, hearts).

## Constraints

- iOS is the strictest target: microphone access in a PWA requires a secure context (HTTPS). See 06.
- macOS (Apple Silicon) first; Windows and Linux supported by design.

## Legal position (informational, not legal advice)

- Content of closed-licence sources (e.g. DW) is downloaded by the user, for personal use, on demand
  into the library. No access control or DRM is circumvented. The repository and release artifacts
  contain code and lists of public URLs, never content.
- The app MUST NOT use third-party logos or brands as its own and MUST NOT redistribute closed content.
- How importers crawl and how sources are credited: 03 ("Importer behaviour", "Rules for every
  provider").

## Success criteria

- The owner and his wife study German with it several times a week, on the laptop and, once they
  come, on phones (plan, "Phones").
- A full Nicos Weg A1 lesson can be done without leaving the app, with speech checked and cards created.
- A new user gets from a fresh machine to lesson 1 quickly (the measure: plan, "Desktop app").
- Adding a new course source requires only a new provider folder (03), no engine or UI changes beyond
  new exercise types if any.
